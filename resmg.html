Integrations

Enterprise-ready.
Africa-native.

Not a bolt-on integration added as an afterthought. M-Pesa and Business Central are first-class citizens of the GTSS engine.

🟢

Safaricom Daraja M-Pesa

Guest taps "Pay via M-Pesa." Backend fires a Daraja API STK Push. A payment prompt pops on their Safaricom phone in under 3 seconds. Confirmation logged automatically to the order ledger.

Daraja API v2 · STK Push · Callback Webhooks
🔵

Microsoft Business Central ERP

Every finalized order queues locally. The moment internet returns, a background worker pushes the full backlog — Sales Invoices, Cash Receipts, Inventory Entries — without duplicates, using UUID idempotency.

OData · OAuth2 · Entra ID · Sync Queue
🌐

Offline-First Local Server

Node.js + SQLite/PostgreSQL runs entirely on your hardware. Zero cloud dependency. Zero subscription risk. The system operates at full capacity with a completely dead ISP connection.

Node.js · SQLite · Redis Cache · Linux/Windows
⚡

Real-Time WebSocket Engine

Socket.IO keeps every device in the building perfectly synchronized on the local network. Kitchen swipes Ready → Waiter's device pings in milliseconds → Guest's tracker updates instantly.

Socket.IO · Local LAN · Sub-100ms Latency
