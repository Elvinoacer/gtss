System Architecture

HOW THE ROLES
CONNECT

Every order placed by a guest propagates through the full system — socket-synced in real time to kitchen, waiter, and admin simultaneously.

◉
Guest
Places order
via device UI.
No login required.
◈
Kitchen
Receives live order.
Advances through
kanban statuses.
◆
Waiter
Gets assigned order.
Delivers + confirms
payment at table.
◇
Admin
Monitors all lanes.
Manages team,
menu, analytics.
